# Preview build 15 — file meaning and interaction continuity

Published from clean source `80d44e0c92d985135d4968ffe8fc89193c47f6c6`.
This release improves three concrete task paths:

- Opening and closing host controls preserves a custom surface's draft, selection
  and scroll; covered content does not continue receiving keyboard input.
- The model can read the same bounded file preview as the user through the
  existing runtime envelope. Spreadsheet cells include absolute coordinates and
  distinct saved, missing and visually hidden formula-result states.
- An iPhone attachment link enters the authenticated download/share flow rather
  than replacing the only conversation document. Closing sharing retains the
  conversation and draft.

Implementation and limitations are described in [surface input](../reviews/2026-10-05-surface-input.md),
[file reading](../reviews/2026-10-05-file-runtime.md), and [iOS](../ios.md).

## Validation

The final `npm run check` passed **983 Python tests** (7 opt-in skips), **343
frontend tests**, TypeScript and the production build. Doctor confirmed Python
3.14.8T with the GIL disabled. Focused suites overlap these totals.

Offline WebKit acceptance passed 48 modal/input checks, 36 whole-App checks and
17 spreadsheet checks. iPhone 16 Pro Max / iOS 18.1 Simulator acceptance passed
11 native checks. Simulator sharing uses a synthetic completion callback;
physical-device installation, keyboard, VoiceOver and share extensions remain
unverified.

Five isolated paid model evaluations are recorded in the file-reading review,
including their failures. The last one correctly delivered the byte-identical
copy, cited B7 and explained the three formula states without an extra component
or a tool error. This is one observed successful task, not a general success
rate. Earlier intermittent command errors remain undiagnosed.

After deployment, a separate browser tab verified draft entry, menu-to-settings
replacement, return, continued typing and reload recovery on the public site.
No model task was submitted during this UI check. The synthetic draft was then
cleared; the user's original tab was retained.
