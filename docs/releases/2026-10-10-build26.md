# Preview build 26 — quit, return, continue

Build 26 adds **Quit Athena** to the fixed desktop companion menu. Quitting uses
the existing draft-save and native shutdown path; hiding Athena remains a
separate action. A failed draft flush cancels the quit instead of discarding
the draft. Generated components and subframes cannot invoke the native quit
bridge. The menu label is available in all nine supported UI languages.

Built from clean source `68fdbc78d546a21fb2135ff74be292392987eeb9`.

## Installed-app acceptance

The installed app was exercised through Computer Use, not only a native fixture:

- Choosing Quit ended both the app and its backend and closed the backend port.
  Reopening restored the current synthetic conversation and the unsent draft.
  All 325 message rows present before installation remained unchanged.
- A follow-up changed the lighting price in a synthetic quotation from 3,000 to
  3,200. The original Excel file and registered desktop panel were reused. The
  preview showed A = 13,200, B = 13,500, and a difference of 300. The panel kept
  its saved position and 820 × 510-point size; there was one latest active
  component for the file.
- The published demonstration consists of separately captured application
  windows containing only synthetic data. It is **not a continuous recording**.

See the [actual demonstration](https://featherhk.com/athena/#demonstration).

## Fresh local-source acceptance

A clean checkout and an empty external data directory were started without
cloud credentials or an inherited operator environment. The local model setup
opened without a Feather account. An authorized provider key was entered in
the local configuration UI and kept out of the repository and public evidence.

A real DeepSeek `deepseek-flash` task created a quotation workbook, then updated
the same file after a missing installation price was supplied. Downloaded XLSX
cached values independently matched totals of 13,000 and 13,500. Stopping a
subsequent running command persisted an interrupted run. Restarting and
reloading restored the result without additional model requests or replayed
commands. This was a clean checkout on the existing development Mac, not an
independent clean-machine installation.

The provider reported 114,459 prompt tokens, 6,366 completion tokens, and
104,832 prompt-cache-hit tokens across 13 requests in this acceptance flow.
These are API usage counters, not a reconciled billing statement. The temporary
configuration and credentials were removed after validation.

## Boundaries

The downloadable package uses hosted account access; local source mode uses a
user-configured provider connection. Public registration starts with zero
credit. Recharge is not active: no receiving wallet or live merchant service
has been configured. Source publication is a separate step and is not implied
by this binary release.

Task continuity is verified within the current conversation. This does not
establish automatic routing among concurrent tasks, unrestricted desktop
control, or an integrated fullscreen effects host. macOS 13 is a deployment
target, not a claim that every macOS release was tested.

Two 60-second idle samples measured the native host at about 2.73% of one CPU
core, and the Python backend at 1.43% expanded / 1.57% collapsed. WebKit helper
processes were not attributed; these samples do not establish that all reported
lag has been resolved.
