## User-visible changes

The default layout keeps the logo, presence emblem and input in place while the
conversation scrolls. Reading no longer shrinks the emblem and shifts the text.
Long drafts grow upward to a bounded height, preserving the bottom edge, focus,
selection and composition; clearing a draft restores a single line.

Generated images, Markdown, HTML, DOCX body content and XLSX sheets appear within
the conversation. Workspace components are also inline by default; full-screen
focus remains explicit. Same-path file updates receive observable revisions, so
ordinary output previews can refresh without opening a separate workspace.

A registered session renderer can own the complete communication work area and
lay out messages, images and typed document data using ordinary HTML/CSS/SVG or
Canvas. It can read canonical messages, synchronize a draft and invoke bounded
host actions. Independent stop, account and recovery controls remain reachable.
The [surface contract](../surface-renderer.md) documents actual behavior and
boundaries; this does not claim unrestricted parent-DOM or network access.

Native Mac and iOS recovery can load the default interface independently of a
broken renderer. Context preflight also counts the complete provider payload,
including frozen tool schemas and admitted notes, before deciding to compact.
