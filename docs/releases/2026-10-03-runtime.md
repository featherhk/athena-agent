## What changed

Hosted web and iOS can use account-scoped Linux commands and managed Chromium.
The short capability observation distinguishes server execution from control of
someone's phone. Cloud browser login handoff is explicitly unavailable; it no
longer instructs a mobile user to interact with an invisible server window.

Activity distinguishes an unsuccessful command, an uncertain effect and an
ended run. Raw results and reasoning remain expandable. Reading an expanded
record delays automatic client refresh. Free-form surfaces support accessible
pointer/keyboard interaction regions while the rest of the overlay passes input
through to the conversation. Component state and bridge identity are scoped to
account/conversation/version.
