# Preview build 16 — Mac desktop companion

Built from clean source `36630fa2cc1904f60d29ff43a7771a067cfb8837`.
This Mac-first preview replaces the default chat window with a recallable
appearance and input. Windows remains deferred.

- Option–Space shows or hides Athena and its registered desktop components.
  Hiding preserves the conversation, draft and running task; it ends microphone
  capture and playback. Recall does not start recording automatically.
- Answers and required account/help interactions expand on demand. History,
  settings and recovery remain reachable from the native menu bar.
- Registered components can occupy separate native desktop panels. The runtime
  can inspect actual desktop state separately from desired registration.
  Placement changes preserve the component document, draft and selection.
- CLI execution remains available on the Mac. Agent-authored components remain
  outside application source; native reset restores the default presentation
  while retaining chats and files.

## Validation

The clean-source `npm run check` passed **1,012 Python tests** (7 skips), **373
frontend tests**, TypeScript, the production build and repository checks.
Doctor confirmed Python 3.14.8T with the GIL disabled after dependency imports.

The native host passed 18 focused checks; six native recovery checks also
passed. An additional integration check used the final release frontend in
native WebKit, mounted a real registered component, changed placement without
losing its draft/selection, and submitted once through the parent App receipt
flow. Offline production-React WebKit acceptance passed 22 interaction checks.
These account and server fixtures are synthetic; they do not establish actual
microphone acoustics or cross-application pointer delivery.

Separately, the packaged backend used a fresh disposable local data directory
to authenticate the existing authorized test account against the live cloud
service, verify positive available credit and complete a real model-driven
local CLI task. The returned macOS version matched the host. The temporary
login was ended and the backend shut down; existing chats were unchanged.
An earlier production-backend task also queried local disk space. Its prose
mislabelled GiB as GB, so that check is execution evidence, not an exact-unit
answer-quality pass.

The relocated bundle passed two isolated backend starts, authentication and
origin boundaries, GIL-free imports and graceful shutdown. The DMG passed
integrity verification, mounted nested-signature checks and the Applications
link check. Bundled backend source matched the clean release clone; unrelated
execution-client work in the development checkout was excluded.

## Remaining acceptance

Real WindowServer click passthrough into another application, physical multiple
displays and real microphone/call behavior remain unverified. The host was tested
on macOS 15.4.1; the deployment target is not a compatibility test of every
supported OS release. Native recovery is independent of generated components,
but the current Stop menu still relies on the trusted WebKit page being
responsive. This is not a claim of unrestricted control of Finder or arbitrary
third-party applications.

See [the acceptance review](../reviews/2026-10-09-mac-companion.md) and
[desktop contract](../desktop-surface-contract.md) for the tested boundaries.
Raw receipts, account state, logs and captures remain outside source control;
the public download receipt is `/tmp/athena-build16-publication.json`.
