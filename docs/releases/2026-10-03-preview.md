## Operations and limits

The active Compose files are `/opt/athena/releases/5bcda5a/deploy/compose.yaml` and `images.yaml`; use both for maintenance. `/opt/athena/current` selects this release. A private consistent state backup was created at `/var/backups/athena/20261003-release-5bcda5a/` before stopping/replacing only Athena's Python services. Preserve current credit records when rolling back code; restoring an old ledger could restore already-spent credit.

The app is Apple Silicon only, ad-hoc signed and **not Apple-notarized**. A clean second Mac and Gatekeeper on a browser-quarantined download remain unverified. Browser operation requires installed Chrome/Chromium; automatic browser provisioning/upgrades are not implemented. The managed adapter is macOS-only; hosted Linux shell and browser execution remain disabled pending proper isolation. Full desktop control, browser vision input and real audio calls are not complete. Mac and web conversations are separate despite shared account authentication. No recharge or payments are open.
