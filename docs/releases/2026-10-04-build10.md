## Included changes and acceptance

The native **Athena → Check for Updates…** menu checks the fixed HTTPS feed independently of the local backend and login service. It compares version, build and source identity; missing or mismatched metadata never claims the app is current. Requests reject redirects and use no account credentials or cookies. This is manual update discovery: it does not download, install, restart or overwrite the app. After awaiting the response, it also checks whether another native sheet has opened before displaying its result.

The source snapshot also includes independent Stop availability with a draft present, cancellation of submissions still awaiting preflight, shared typed/spoken clarification drafts, same-file input reselection and UTF-8 filename encoding for output previews/downloads. These changes are bundled in this desktop release; this note does not attest which source is currently deployed to the hosted web service.
