## Interaction changes

Historical Markdown no longer reparses on every draft or streamed update.
Completed activity stops fetching on unrelated session cursors, and floating-panel
geometry observers are absent when no floating panel needs them. Upward reader
gestures now pause transcript following immediately, instead of being overridden
by the former 160-pixel bottom threshold. Returning to the bottom or explicitly
sending resumes following; targeted activity navigation stays at the chosen
result. Hidden work/voice animations no longer run while idle.

The [performance review](../reviews/2026-10-04-mac-interaction-performance.md)
records the component benchmark and ten offline WKWebView assertions, including
the reproduced before/after scrolling defect. These use synthetic content and do
not establish physical trackpad latency, every real IME behavior or human-perceived
smoothness in the user's installed app. The existing build 9 was left running.

## Recharge implementation and activation boundary

Source includes the optional [credit top-up integration](../recharge.md): durable
account orders, a BTCPay invoice adapter, signed notifications, independently read
settlement, atomic credit and a localized account-panel flow. No real wallet,
payment account, address or merchant configuration was provisioned. **Public paid
recharge remains disabled.** Gateway deployment, operator-controlled configuration
and real settlement acceptance are still required. The new desktop gracefully
handles the currently older gateway's explicitly disabled recharge capability.

The hosted runtime was still `f817045` during this release. A read-only preflight
reported one `waiting_user` run; it was not interrupted or refreshed by a runtime
cutover. Static DMG publication does not deploy new backend routes.
